# Scan & Go - Smart Retail Platform

A queue-free smart retail platform that enables customers to scan items using their smartphones and pay directly through the app, skipping traditional checkout lines.

## ✨ Key Features

-   **Barcode Scanning**: Quick and reliable barcode scanning using the device's camera.
-   **ML-Powered Analytics**: Real-time insights and inventory optimization powered by machine learning.
-   **Merchant Dashboard**: Comprehensive dashboard for store owners to manage inventory and monitor sales.
-   **PWA Core**: React-based Progressive Web App for a seamless, installable user experience.

## 🏗️ Project Structure

-   `frontend/`: React.js Progressive Web App (PWA).
-   `backend/`: high-performance FastAPI Python backend.
-   `ml/`: Machine learning models and training scripts.
-   `database/`: SQL schemas and migration scripts.
-   `docker/`: Containerization configuration.
-   `.github/workflows/`: CI/CD automation with GitHub Actions.
